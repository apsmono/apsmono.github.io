# Photos

Drop your two portrait photos here with these exact names:

- `hero.jpg`  — large portrait shown in the hero (recommended: the black-suit /
  white-shirt studio shot, image 1). Displayed at a 4:5 ratio, top-aligned.
- `about.jpg` — portrait shown in the About section (recommended: a relaxed,
  smiling seated shot, e.g. image 5). Displayed at a 3:4 ratio, rendered in
  grayscale that fades to color on hover.

Any reasonably high-res JPG/PNG works — the layout uses `object-cover`, so
different aspect ratios will still crop cleanly. If a file is missing, the site
falls back to the GitHub avatar automatically.

Tip: keep each file under ~500 KB for fast loads (resize to ~1200px on the long
edge and export at ~80% quality).
